# Cohort360 — Cohort & Programme Management Platform

Cohort360 is a web-based prototype designed to bring programme and cohort management activities into one centralised platform.

## Live Demo

[**Launch Cohort360**](https://khensanintombela.github.io/Cohort360/)

## Features

- **Dashboard:** View programme activity, attendance trends, progress, and recent activity.
- **Programme & Cohort Management:** Organise programmes and groups.
- **Candidate Management:** View and organise candidate records.
- **Staff Management:** Manage staff information and permissions interfaces.
- **Attendance Tracking:** Monitor attendance across sessions and groups.
- **Assignments, Assessments & Quizzes:** Organise learning activities and track progress.
- **Chat:** Explore the communication interface.
- **Reports:** Review programme and candidate progress.
- **Custom Fields:** Configure additional candidate information fields.
- **Settings & Permissions:** Explore platform settings and role-based permission interfaces.
- **Search & Filters:** Find records using available search and filtering controls.
- **Appearance:** Explore the available visual themes.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser local storage for demo data persistence
- GitHub Pages for static hosting

## Getting Started

1. Open the [live demo](https://khensanintombela.github.io/Cohort360/).
2. Explore the dashboard and navigation.
3. Visit the different sections to explore the available interface and interactions.

## Project Status

Cohort360 is a browser-based prototype. Features and data persistence depend on the implemented client-side functionality. Browser local storage is specific to the browser and device; a production multi-user platform would require a shared backend, database, and appropriate authentication.

## Privacy Notice

Use fictional information when exploring the demo. Do not enter real personal, confidential, or sensitive information.
